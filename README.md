# Stoffwechsel Code – Live-Training

Mobile-first Landingpage für das kostenlose Live-Training am 14. September.

## Veröffentlichung

Das Projekt ist für Netlify vorbereitet. Es benötigt keinen Build-Schritt; das Veröffentlichungsverzeichnis ist der Projektordner selbst.

## Dateien

- `index.html` – Seiteninhalt und GetResponse-Einbindung
- `styles.css` – vollständiges responsives Design
- `script.js` – direkter Sprung zum Anmeldeformular
- `netlify.toml` – Netlify-Konfiguration
- `assets/` – Logo, Trainerinnenfoto und Erfahrungsbericht
